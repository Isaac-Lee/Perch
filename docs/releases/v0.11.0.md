## Perch v0.11.0

앱을 다시 열 때 열려 있던 칸을 복원하고, 검수에서 찾은 버그·성능·접근성 문제를 함께 고친 릴리스다.

### 새로 더한 것

- 앱을 다시 열면 열려 있던 칸과 배치를 복원한다. Hermes 칸은 같은 대화를 이어서 열고, 셸과 OpenCode 칸은 같은 폴더에서 새로 연다. 설정 → New session → Restore로 끈다. (#58)

### 다듬은 것

- 1초 시계가 열린 칸 전체와 채팅 기록을 다시 그리지 않는다. 경과 시간은 작업 중인 칸만 1초마다 바뀐다. (#47)
- 세션 패널이 1초마다 모든 세션을 다시 묶고 정렬하지 않는다. 오래됨 표시 같은 시간 경계는 최대 1분 늦게 바뀔 수 있다. (#48)
- Settings, New session, 단축키 도움말, 정렬 메뉴를 Esc로 닫는다. 닫으면 포커스가 메뉴를 연 버튼으로 돌아간다. (#50)
- 시스템의 "동작 줄이기"를 켜면 상태 점이 깜빡이지 않는다. (#51)
- 세션 행을 키보드와 화면 낭독기로 쓸 수 있게 구조를 고쳤다. 키보드로 포커스하면 Stop·Hide·Archive 버튼이 보인다. (#52)
- 화면 언어 규칙에 맞게 일부 라벨을 영어로 바꿨다 (Stopping…, Running, Failed). (#53)
- 30일 넘게 쓰지 않은 끝난 세션의 상태 파일을 앱 시작 때 정리한다. (#46 일부)
- 웹뷰에 CSP를 걸어 앱 밖 주소로 접속하거나 스크립트를 불러오지 못하게 했다. (#49)

### 고친 것

- 처음 실행할 때 New session의 기본 폴더가 빈 값이 되던 문제를 고쳤다. 없는 폴더로는 세션을 열지 않는다. (#40)
- 창을 둘 이상 열면 보관·읽음·순서 설정을 서로 덮어쓰던 문제를 고쳤다. (#45)
- 여러 개 고르는 질문에 답할 때 `(Recommended)` 꼬리표가 답에 그대로 붙던 문제를 고쳤다. (#41)
- 터미널에 큰 글을 붙여 넣는 동안 다른 칸이 멈출 수 있던 문제를 고쳤다. (#42)
- `PERCH_HOME`이 빈 값이면 훅과 앱이 다른 폴더를 보던 문제를 고쳤다. (#43)
- Hermes `config.yaml`의 perch 블록 끝 표시가 없을 때 Connect/Disconnect가 파일의 나머지를 지우던 문제를 고쳤다. 이제 아무것도 쓰지 않고 오류를 알린다. (#44)
