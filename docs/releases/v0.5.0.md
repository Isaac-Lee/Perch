## Perch v0.5.0

새 기능 하나와 고친 것 하나를 담은 릴리스다.

### 새로 더한 것

- 세션 칸 상단바의 오브가 생각할 때만 나오던 것을, 작업 중인 모든 상태에서 나오게 했다. 하는 일마다 오브 모양과 라벨이 다르다: 생각(Thinking), 답 쓰기(Writing), 파일 읽기와 검색(Searching), 파일 수정(Editing), 명령 실행(Running), 서브에이전트(Delegating), MCP 도구(Connecting), 그 밖의 도구(Working). 라벨 옆 시간은 이번 턴이 시작된 때부터 잰다. 라벨에 마우스를 올리면 지금 다루는 파일이나 명령이 보인다. 하단 오브도 같은 모양을 따른다. Claude Code와 Hermes 도구 이름을 모두 알아본다.

### 고친 것

- New session 메뉴의 최근 폴더 목록에 같은 폴더가 여러 번 나오고 지울 수 없던 문제. 대소문자, `/`와 `\`, 끝의 `\`만 다른 경로를 같은 폴더로 본다. 이미 저장된 중복은 앱을 열 때 정리된다. 선택하지 않은 폴더 줄에 마우스를 올리면 X 버튼이 나오고, 누르면 목록에서 빠진다.

### 설치
