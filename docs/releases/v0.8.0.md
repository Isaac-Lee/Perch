## Perch v0.8.0

세션의 서브에이전트와 백그라운드 작업을 그래프로 한눈에 보는 릴리스다.

### 새로 더한 것

- 세션에 서브에이전트나 백그라운드 작업이 생기면 칸 머리줄에 그래프 버튼이 나온다. 숫자는 실행 중인 개수다.
- 누르면 그 세션 안에 그래프가 붙는다. 칸이 넓으면 오른쪽, 좁으면 아래에 나온다.
- 맨 위가 이 세션이고, `delegate_task` 호출마다 한 행, 마지막 행이 백그라운드 작업이다. 위에서 아래로 꺾인 선으로 잇는다.
- 노드에는 상태, 목표, 모델이 보인다. 실행 중이면 생각 중 구슬과 지금 하는 작업이 나온다.
- 서브에이전트 노드를 누르면 요약, 토큰, 마지막 출력이 펼쳐진다. 백그라운드 노드를 누르면 그 세션으로 이동한다.
- 패널 세션 행의 `N agents`나 `└ Background` 줄을 눌러도 그래프가 열린다.
- 터미널(TUI) 칸에서는 백그라운드 작업과 훅이 알려 준 서브에이전트만 보인다.

### 다듬은 것

- 채팅 입력창에서 위/아래로 이전 요청을 불러올 때 지금 위치(`3/12`)를 보여준다.
