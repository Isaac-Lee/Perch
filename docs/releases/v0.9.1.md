## Perch v0.9.1

검수에서 나온 채팅·사이드바·칸 문제를 고친 릴리스다.

### 다듬은 것

- 좁은 칸에서 입력창 줄이 접혀 칩과 보내기 버튼이 다음 줄로 내려간다.
- 흐린 글자(도구 줄, 안내 문구, 칩)의 대비를 높였다.
- 여러 개를 고르는 질문에서는 선택지를 여러 개 고른 뒤 보내기로 답한다.
- gateway 재시작 버튼이 멈추는 동안 "멈추는 중…"으로 바뀌고 눌리지 않는다.
- 이미지가 올라가는 동안 "이미지 올리는 중…"을 보여주고 보내기를 막는다.
- 긴 대화에서 답이 흘러나올 때 이전 메시지를 다시 그리지 않는다.

### 고친 것

- 크론 작업, 부모를 찾지 못한 백그라운드 실행, 예전 서브에이전트 세션, 대화가 한 번도 없었던 세션이 상태 탭에 내가 시작한 세션처럼 보이던 문제를 고쳤다.
- 백그라운드 작업 알림이 대기 중 메시지 카드로 보이던 문제를 고쳤다.
- 세션을 이어 열면 숨은 메시지나 펼친 스킬 본문이 내 말풍선으로 보이던 문제를 고쳤다. gateway가 만든 메시지는 시스템 줄로 보인다.
- 대기 중 메시지가 거절되면 진행 중인 작업까지 멈춘 것처럼 보이던 문제를 고쳤다. 거절된 글은 입력창으로 돌아온다.
- gateway가 작업 중에 꺼진 뒤 새 메시지가 계속 대기에만 머물던 문제를 고쳤다.
- 다시 연결한 뒤 실행 중이던 백그라운드 줄이 사라지고, 끝난 서브에이전트가 계속 실행 중으로 남던 문제를 고쳤다.
- hook이 연결되지 않은 상태에서 채팅 칸의 사이드바 행이 사라지던 문제를 고쳤다.
- 에이전트가 설치되지 않았거나 바로 꺼질 때 칸이 바로 사라져 오류를 볼 수 없던 문제를 고쳤다. 이제 칸이 남고 종료 코드를 보여준다.
