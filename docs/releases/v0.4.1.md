## Perch v0.4.1

고친 것 위주의 릴리스다.

### 고친 것

- 답변 안의 표가 표로 보이지 않고 `|` 문자로 보이던 문제. 문장 바로 다음 줄에 오는 표를 문단으로 잘못 읽었다. 셀 안의 `\|`, 칸 수가 안 맞는 행, 정렬(`:---:`)도 처리한다.
- 채팅 보기가 게이트웨이의 실행 상태를 따른다. 게이트웨이가 턴이 끝났다고 알리면 맨 아래 상태 줄, 세션 줄, 칸 머리줄이 함께 풀린다.
- 작업 중인데 45초 동안 아무 소식이 없으면 게이트웨이에 상태를 다시 묻는다.
- Stop을 눌러도 끝났다는 신호가 없으면 상태를 다시 맞춘다. Hermes가 아직 실행 중이라고 답하면 그 사실을 알리고, Stop을 한 번 더 누르면 Perch의 표시만 정리한다.
- 앱을 올린 뒤 Hermes 훅이 이전 버전으로 남아 있으면 시작할 때 자동으로 고친다. 고칠 수 없으면 설정에 Update 버튼이 나온다. (0.4.0은 Connect를 다시 눌러야 Reply needed가 동작했다.)
- 0.23.1보다 오래된 Hermes에도 연결된다. 이전 Hermes가 띄운 게이트웨이가 남아 있으면 바꿔서 붙고, `gateway attach`가 없는 CLI면 Perch가 직접 `hermes serve`를 띄워 연결한다. 연결에 실패하면 Hermes가 알려준 이유를 그대로 보여준다.
- Windows 창 맨 위 제목 표시줄이 테마를 따른다. Light는 밝게, Dark·Midnight·Black은 어둡게 나온다.

### 알려진 한계

- Thinking으로 남는 문제는 원인을 확정하지 못했다. 위임 작업이 낀 턴을 실제 게이트웨이에서 여러 번 돌렸지만 다시 일어나지 않았다. Hermes가 턴을 끝내지 않고 멈춘 경우라면 Perch는 알리고 표시를 정리할 수만 있다. 다시 생기면 Hermes `agent.log`의 "tui prompt accepted"와 "tui turn finished" 줄을 확인한다.
- 상태를 다시 맞추면 슬래시 명령 출력 같은 Perch가 넣은 줄은 사라진다.
