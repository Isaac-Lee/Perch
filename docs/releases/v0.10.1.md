## Perch v0.10.1

0.10.0의 되감기·편집·포크 버튼이 보이지 않던 문제를 고친 릴리스다.

### 고친 것

- 답이 빨리 끝난 턴(오류로 끝난 턴 등) 뒤에 내 말풍선에 마우스를 올려도 `⟲ 되감기 · ✎ 편집 · ⑂ 포크`가 나오지 않던 문제를 고쳤다. gateway가 턴을 끝냈다고 알린 직후에도 아직 실행 중으로 답하면, 잠시 뒤 다시 확인한다.

### 설치

| OS | 파일 |
|---|---|
| Windows 10/11 (x64) | `Perch_0.10.1_x64-setup.exe` |
| macOS (Apple Silicon) | `Perch_0.10.1_aarch64.dmg` |

Hermes 연결 방법은 [README](https://github.com/Isaac-Lee/Perch#hermes-연결)를 본다.
