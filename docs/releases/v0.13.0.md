## Perch v0.13.0

Hermes 채팅 보기에 작업 목록 패널, 코드 구문 강조와 자동 정리, 더 또렷한 글자 표현을 더하고, 사이드바에 todo가 뜨지 않던 것을 고친 릴리스다.

### 새로 더한 것

- Hermes가 세운 작업 목록(todo)이 채팅 칸 입력창 위에 뜬다. 남은 항목이 없으면 사라지고, 머리줄을 누르면 접힌다. 세션을 다시 열어도 목록이 돌아온다. (#89)
- 코드 블록을 highlight.js로 구문 강조한다. 언어를 적지 않은 블록은 언어를 추정해 확실할 때만 색을 입히고, 머리줄에 추정한 언어를 보여준다. (#87)
- 한 줄로 온 긴 JSON과 HTML/XML 코드 블록을 화면에서 줄을 나눠 보여준다. 복사 버튼은 원문을 그대로 복사한다. (#87)
- `- [ ]` / `- [x]` 작업 항목을 체크박스로 그린다. (#88)

### 다듬은 것

- 굵은 글씨, 제목, 표 머리를 실제 Bold 글꼴로 그린다. 제목은 단계별로 크기가 다르고, `__굵게__`와 `***굵은 기울임***`도 처리한다. (#88)
- 인라인 코드, 인용문, 구분선, 표의 줄무늬가 배경과 더 잘 구분된다. (#88)
- 코드 복사 버튼이 복사 뒤 `복사됨`을 잠깐 보여주고, diff의 추가·삭제 줄은 줄 전체에 색을 입힌다. (#87)

### 고친 것

- 사이드바 세션 행에 Hermes todo가 뜨지 않던 것을 고쳤다. Hermes가 도구 이름을 `todo_list`로 바꾼 뒤로 훅이 목록을 기록하지 못했다. 일부 항목만 고치는 호출에도 전체 목록이 유지된다. (#89)
