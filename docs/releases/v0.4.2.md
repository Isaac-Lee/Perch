## Perch v0.4.2

고친 것 하나를 담은 릴리스다.

### 고친 것

- New session 메뉴의 최근 폴더 목록에 같은 폴더가 여러 번 나오고 지울 수 없던 문제. 대소문자, `/`와 `\`, 끝의 `\`만 다른 경로를 같은 폴더로 본다. 이미 저장된 중복은 앱을 열 때 정리된다. 선택하지 않은 폴더 줄에 마우스를 올리면 X 버튼이 나오고, 누르면 목록에서 빠진다.

### 설치

| OS | 파일 |
|---|---|
| Windows 10/11 (x64) | `Perch_0.4.2_x64-setup.exe` |
| macOS (Apple Silicon) | `Perch_0.4.2_aarch64.dmg` |

Hermes 연결 방법은 [README](https://github.com/Isaac-Lee/Perch#hermes-연결)를 본다.
