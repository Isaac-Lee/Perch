## Perch v0.11.3

Hermes 채팅 보기에서 순수 ASCII 상자 그림과 백슬래시 이스케이프 표시를 고친 릴리스다.

### 고친 것

- `+---+`와 `|`로 그린 상자 그림의 세로선이 줄마다 끊겨 보이던 것을 고쳤다. 화면에는 상자 문자로 이어서 그리고, 복사 버튼은 원문을 그대로 복사한다. 언어를 적지 않은 코드 블록, 도구 결과, 사용자 메시지에 적용된다. (#74)
- 코드 블록 없이 온 상자 그림에서 빈 줄로 떨어진 `▼`, `|`, `v` 같은 연결 조각이 따로 문단으로 그려지던 것을 고쳤다. 앞 그림과 한 블록으로 보여준다. (#74)
- `\*`, `\_` 같은 백슬래시 이스케이프가 백슬래시째 보이던 것을 고쳤다. `C:\dir\*.txt`처럼 Windows 경로로 보이는 낱말은 그대로 둔다. (#74)
