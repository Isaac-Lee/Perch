## Perch v0.10.2

되감기·편집·포크를 검수하다 찾은 문제를 고치고, 서브에이전트 그래프에서 끝난 작업을 숨길 수 있게 한 릴리스다.

### 다듬은 것

- 서브에이전트 그래프에서 끝난 서브에이전트와 백그라운드 작업을 기본으로 숨긴다. 머리줄의 `완료 N개 보기`를 누르면 다시 보이고, 고른 설정은 기억한다. 끝난 서브에이전트라도 아래에서 아직 도는 작업이 있으면 트리가 끊기지 않게 남는다. (#32)

### 고친 것

- 한글 입력기를 켠 채 입력창에 포커스가 있으면 편집·덮어쓰기·포크·이미지 첨부 같은 버튼을 두 번 눌러야 반응하던 문제를 고쳤다.
- 이미지를 붙인 메시지에 Hermes가 붙인 `[Image attached at: …]`, `[screenshot]` 줄이 말풍선에 그대로 보이던 문제를 고쳤다. 이제 글과 이미지 개수만 보이고, 편집할 때 이미지도 그대로 남는다.

### 설치

| OS | 파일 |
|---|---|
| Windows 10/11 (x64) | `Perch_0.10.2_x64-setup.exe` |
| macOS (Apple Silicon) | `Perch_0.10.2_aarch64.dmg` |

Hermes 연결 방법은 [README](https://github.com/Isaac-Lee/Perch#hermes-연결)를 본다.
