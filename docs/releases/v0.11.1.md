## Perch v0.11.1

세션 상태를 지켜보는 백그라운드 작업이 쉬는 동안 일을 덜 하게 한 릴리스다.

### 다듬은 것

- 상태 파일도 열린 칸도 바뀌지 않으면 세션 목록을 다시 만들지 않는다. 세션이 많이 쌓여도 쉬는 동안의 비용이 늘지 않는다. (#46)
- 30일 넘게 쓰지 않은 끝난 세션의 상태 파일을 앱 시작 때만이 아니라 한 시간마다 정리한다. 앱을 오래 켜 두어도 파일이 쌓이지 않는다. (#46)
- README의 세션 패널 설명에 목록 규칙을 적었다. 칸 없는 세션은 7일 뒤 목록에서 빠지고, 끝난 세션은 30일 뒤 보관 목록에서도 지워진다.

### 설치

| OS | 파일 |
|---|---|
| Windows 10/11 (x64) | `Perch_0.11.1_x64-setup.exe` |
| macOS (Apple Silicon) | `Perch_0.11.1_aarch64.dmg` |

Hermes 연결 방법은 [README](https://github.com/Isaac-Lee/Perch#hermes-연결)를 본다.
