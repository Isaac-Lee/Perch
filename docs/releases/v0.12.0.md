## Perch v0.12.0

Hermes 채팅 보기에서 작업 중에도 메시지를 편집·되감기하고 사이드바에서 포크할 수 있게 하고, 한글이 섞인 상자 그림의 줄 맞춤을 고친 릴리스다.

### 새로 더한 것

- 작업 중에도 내 메시지를 편집하거나 되감을 수 있다. 확인하면 대기 중인 메시지를 취소하고 진행 중인 작업을 멈춘 뒤 그 메시지로 되감으며, 편집이면 고친 글을 바로 보낸다. 확인 문구가 이를 알려 준다. (#76)
- 사이드바 세션 행에 포크 버튼을 더했다. Hermes 채팅 칸이 열린 세션에서 대화 끝에서 포크해 새 칸으로 연다. (#76)
- 포크는 작업이 끝난 뒤에만 된다. 작업 중이거나 대기 중인 메시지가 있으면 말풍선의 포크, "포크해서 보내기", 사이드바 포크가 모두 막힌다. (#76)

### 고친 것

- 한글을 한 칸으로 세어 그린 상자 그림의 세로선이 테두리와 어긋나 보이던 것을 고쳤다. 화면에서만 한글 글자 수만큼 여백 공백을 덜어 줄을 맞추고, 복사 버튼은 원문을 그대로 복사한다. (#78)
