## Perch v0.4.0

채팅 보기가 Hermes 화면에 가까워졌고, 칸과 세션을 직접 배치할 수 있다.

### 새 기능

**채팅 보기**
- 코드 블록 구문 강조 (diff 포함).
- 슬래시 명령. `/`를 치면 명령과 인자 자동완성이 뜨고 Enter로 실행한다.
- `/model <이름> [--provider <slug>]`로 목록에 없는 모델(사내 모델 등)을 지정한다.
- 추론 강도 선택. 모델 칩 오른쪽에서 none부터 ultra까지 8단계로 고른다.
- 모델 목록에 인증되지 않은 provider와 현재 모델도 나온다.
- 작업 중 한 줄 상태 표시. 지금 하는 일과 경과 시간을 보여준다.
- 모델의 추론은 접힌 "생각" 줄로 보인다.
- 연달은 도구 호출은 한 줄로 묶인다. 펼치면 인자, diff, 결과가 보인다.

**칸 배치**
- 칸이 가로로 나란히 놓인다. 3칸이면 세로로 긴 3열, 넓은 화면은 4열이다.
- 칸 머리줄을 끌어 다른 칸의 가장자리에 놓으면 배치가 바뀐다. 배치는 저장된다.
- 모든 칸 머리줄에 종류 아이콘이 나온다.

**세션 패널**
- 세션을 끌어 순서를 바꾼다.
- 정렬 기준을 고른다: Status, Recent activity, Name, Manual order.
- X는 목록에서 내린다 (Recent로 옮긴다). 보관은 별도 버튼이다.
- 답변이 질문으로 끝나면 Done 대신 Reply needed로 나온다.

**사용량**
- 그래프 막대에 마우스를 올리면 정확한 토큰 수와 입력/출력/캐시 분해가 나온다.
- 큰 수는 B 단위로 쓴다.

**테마**
- 설정에서 Dark, Midnight, Black, Light를 고른다. Light에서도 터미널 칸은 어두운 색을 유지한다.

### 바뀐 점

- 입력창의 빛나는 테두리 효과와 깜빡이는 커서를 없앴다.
- 전송 버튼은 항상 보인다. 보낼 내용이 없으면 흐리게 나온다.
- 입력창 안내 문구는 한 줄로만 나오고, 자리가 없으면 끝이 흐려진다.
- 세션 행의 X는 더 이상 보관하지 않는다.
- New session 메뉴와 칸 머리줄의 아이콘을 맞췄다.
- 답변이 끝난 뒤 늦게 온 이벤트(Hermes의 턴 후 검토 작업 등) 때문에 Thinking으로 남던 문제를 고쳤다. Stop을 누르면 멈춘 표시가 풀린다.
- 위임(subagent) 작업 표시가 실제로는 동작하지 않던 문제를 고쳤다.
- 모델을 바꿀 때 충돌이 나면 다시 시도하지 않던 문제를 고쳤다.
- 설치 후 Hermes 연결(Connect)을 다시 눌러야 새 상태 표시가 동작한다.

### 알려진 한계

- 이어서 연 세션의 도구 줄에는 걸린 시간이 없다.
- 연결이 끊겼을 때 자동 재연결은 한 번뿐이다.
- 구문 강조는 간단한 토크나이저라 언어 문법을 정확히 따르지 않는다.
- `/new`, `/clear`, `/resume`, `/branch`, `/compress`, `/undo`, `/retry`, `/quit`는 채팅 보기에서 쓸 수 없다. 필요하면 Hermes (TUI)를 쓴다.
- Reply needed는 답변 끝의 물음표를 보는 추정이라 틀릴 수 있다.
- Stop으로 표시를 푼 뒤에도 작업이 실제로 계속 돌고 있으면, 그 턴이 끝날 때까지 idle로 보일 수 있다.
- 사내 모델 환경과 Windows 10에서의 확인은 아직 끝나지 않았다.
- 열 너비와 칸 높이는 끌어서 조절할 수 없다.
- 설치 파일에 코드 서명이 없다. Windows는 SmartScreen에서 "추가 정보 → 실행", macOS는 처음 실행할 때 "확인 없이 열기"를 누른다.
