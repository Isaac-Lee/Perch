## Perch v0.11.2

Hermes 채팅 보기에서 상자 그림과 마크다운이 깨져 보이던 곳을 고친 릴리스다.

### 고친 것

- 한글이 섞인 상자 그림(아스키 아트 다이어그램)의 세로선이 줄마다 끊겨 보이던 것을 고쳤다. 상자 문자가 든 코드 블록, 도구 결과, 사용자 메시지는 줄 간격을 좁혀 선이 이어진다. (#71)
- 코드 블록 없이 온 상자 그림이 가변폭 글꼴 문단으로 그려져 어긋나던 것을 고쳤다. 이제 코드 블록으로 보여준다. (#71)
- 백틱 4개 이상이나 `~~~`로 연 코드 블록이 닫히지 않아 뒤 내용이 모두 코드로 보이던 것을 고쳤다. (#71)
- 중간에 코드 블록이 끼면 번호 목록이 모두 "1."로 보이던 것을 고쳤다. (#71)
- `<br>`, `~~취소선~~`, 이중 백틱 코드가 원문 그대로 보이던 것을 고쳤다. (#71)

### 다듬은 것

- 길어서 잘린 도구 결과에 남은 글자 수를 적는다. 코드 블록의 탭 폭은 4칸이다. (#71)
