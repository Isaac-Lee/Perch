## Perch v0.8.1

서브에이전트 그래프를 다듬고 채팅의 말풍선 중복을 고친 릴리스다.

### 다듬은 것

- 서브에이전트가 다시 띄운 서브에이전트(손자)도 그래프에 보인다. 부모 노드 아래에 붙고, 깊이 제한은 없다. Hermes에서 쓰려면 `delegation.max_spawn_depth`를 2 이상으로 둔다.
- 오른쪽에 붙은 그래프는 한 줄에 노드 하나씩 세로로 놓고, 하위는 들여쓴다.
- 아래에 붙은 그래프는 같은 레벨을 같은 간격으로 옆에 놓고, 하위는 부모 아래 줄에서 시작한다.
- 그래프 머리줄을 끌어 오른쪽과 아래 사이로 옮긴다. 고른 위치는 기억한다.
- 자식이 있는 노드는 `2 agents · 1 tool · 1m 42s`처럼 자식 수를 함께 보여준다.

### 고친 것

- 채팅에서 보낸 요청이 말풍선 두 개로 보이던 문제를 고쳤다.
- 입력창에 포커스가 있을 때 그래프 버튼의 첫 클릭이 무시되던 문제를 고쳤다 (macOS).

### 설치

| OS | 파일 |
|---|---|
| Windows 10/11 (x64) | `Perch_0.8.1_x64-setup.exe` |
| macOS (Apple Silicon) | `Perch_0.8.1_aarch64.dmg` |

Hermes 연결 방법은 [README](https://github.com/Isaac-Lee/Perch#hermes-연결)를 본다.
