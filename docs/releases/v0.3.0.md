## Perch v0.3.0

Hermes 세션을 터미널이 아닌 채팅 화면으로 볼 수 있다.

### 새 기능

**Hermes 채팅 보기**
- 마크다운으로 그려지는 답변. 스트리밍으로 이어서 나온다.
- 도구 호출 줄. 실행 중인지 끝났는지, 걸린 시간과 결과를 보여준다.
- 승인과 질문 요청이 채팅 안에 버튼으로 나온다.
- 이미지 첨부. 입력 상자의 `+` 버튼으로 고르거나 붙여넣는다 (png, jpg, gif, webp).
- 모델 선택. 입력 상자의 모델 칩을 누르면 모델 메뉴가 열린다. 작업 중에는 바꿀 수 없다.
- 입력 상자 오른쪽의 엔터 아이콘이나 Enter로 보낸다. 한글 입력 중의 Enter는 보내지 않는다. 작업 중에는 중지 버튼이 나온다.
- 이어서 열기(resume). 같은 세션을 다시 열면 이전 대화와 도구 줄을 불러온다.
- 연결이 끊기면 한 번 자동으로 다시 연결하고, 안 되면 "다시 연결" 버튼이 나온다.

**New session 메뉴**
- **Hermes**는 채팅 보기, **Hermes (TUI)**는 기존 터미널 보기로 연다.

**세션 패널**
- 세션 행의 X: 열린 칸이 있으면 칸을 닫는다 (Hermes 작업은 계속 돈다). 열린 칸이 없는 세션은 목록에서 숨긴다.

### 바뀐 점

- Hermes 칸은 이제 기본으로 채팅 보기로 열린다. 터미널 화면이 필요하면 Hermes (TUI)를 고른다.
- 채팅 칸을 닫아도 Hermes 작업은 멈추지 않는다. 세션 패널에서 상태를 계속 보고, 다시 열면 이어서 본다.
- 세션 행의 보관 아이콘이 X로 바뀌었다.

### 알려진 한계

- 코드 블록에 구문 강조가 없다.
- 슬래시 명령 자동완성이 없다.
- 추론 강도(reasoning effort) 선택이 없다.
- 이어서 연 세션의 도구 줄에는 걸린 시간이 없다.
- 연결이 끊겼을 때 자동 재연결은 한 번뿐이다.
- 모델 목록에는 인증된 provider의 모델만 나온다.
- 설치 파일에 코드 서명이 없다. Windows는 SmartScreen에서 "추가 정보 → 실행", macOS는 처음 실행할 때 "확인 없이 열기"를 누른다.

### 설치

| OS | 파일 |
|---|---|
| Windows 10/11 (x64) | `Perch_0.3.0_x64-setup.exe` |
| macOS (Apple Silicon) | `Perch_0.3.0_aarch64.dmg` |
