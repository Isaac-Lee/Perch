## Perch v0.7.0

작업 중에 보낸 메시지를 대기 표시하고 바로 보낼 수 있게 한 릴리스다.

### 새로 더한 것

- 채팅 보기에서 작업 중에 보낸 메시지는 입력창 위 얇은 "대기 중" 카드로 뜬다. 긴 메시지는 두 줄까지 보이고 아래가 흐려진다. 마우스를 올리면 전체가 보인다.
- 카드 아래 "지금 보내기"를 누르면 실행 중인 작업에 바로 전달한다 (Hermes `prompt.steer_queued`). 전달되거나 실행이 시작되면 카드는 사라지고 대화에 말풍선으로 남는다.
- 다른 창에서 넣은 대기 메시지와 다시 연결한 뒤의 대기열도 보인다.

### 설치

| OS | 파일 |
|---|---|
| Windows 10/11 (x64) | `Perch_0.7.0_x64-setup.exe` |
| macOS (Apple Silicon) | `Perch_0.7.0_aarch64.dmg` |

Hermes 연결 방법은 [README](https://github.com/Isaac-Lee/Perch#hermes-연결)를 본다.
