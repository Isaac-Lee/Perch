## Perch v0.9.0

세션 전체 시간을 보여주고, 칸 머리줄과 채팅 행의 상태 표시를 맞춘 릴리스다.

### 새로 더한 것

- 세션마다 지금까지 일한 시간을 합산해 보여준다. 훅이 끝난 턴의 시간을 누적해 `busyTotal`로 저장하므로 훅 상태 형식이 바뀌었다. 업데이트 전 턴은 합계에 들어가지 않고, 업데이트한 뒤의 턴부터 센다.

### 다듬은 것

- 칸 머리줄의 오브와 채팅의 진행 행 오브가 같은 상태를 따른다.
- 칸 머리줄에는 활동과 현재 단계 시간만 `Thinking 1s`처럼 짧게 보여준다. 도구 이름 같은 자세한 내용은 툴팁에 있다.
- 칸 하단에는 `Now`, `Turn`, `Session` 시간과 단계 수를 이름을 붙여 보여준다. 끝나면 `Turn`과 `Session`만 보여준다.
- 채팅 진행 행이 머리줄과 같은 단어로 시작한다 (`Running · terminal · npm test`, `Thinking · writing reply`). 시간도 머리줄과 같은 턴 시작부터 센다.
- 백그라운드 행의 제목 앞에 `› Background ·`를 붙인다.

### 고친 것

- 채팅 진행 행의 오브가 항상 작업 중으로 보이던 문제를 고쳤다.
- 선택지가 긴 질문에서 선택지끼리 겹쳐 보이던 문제를 고쳤다.
