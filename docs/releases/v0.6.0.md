## Perch v0.6.0

읽음 표시, 상태별 묶기, 서브에이전트와 백그라운드 작업 보기를 더한 릴리스다.

### 새로 더한 것

- 읽음/안 읽음: 끝난 세션 중 아직 보지 않은 것에 점과 굵은 제목이 붙는다. 그 세션 칸에 포커스를 두거나 패널 행을 누르면 읽음이 된다.
- Needs you: 승인, 질문, 답장이 필요한 세션을 패널 맨 위 한 곳에 모은다. 폴더 이름이 함께 보인다.
- 정렬 메뉴의 Group by: Folder 또는 Status(Needs you / Working / Unread / Done / Idle)로 묶을 수 있다.
- 채팅 입력창에서 위/아래 화살표로 이전 요청을 불러온다.
- 서브에이전트: 채팅 보기에서 delegate_task 아래에 자식마다 목표, 지금 쓰는 도구, 시간이 보인다. 펼치면 요약과 결과가 나온다. 진행 중인 자식은 패널 행에도 보인다.
- 백그라운드 작업: Hermes `/background` 실행이 부모 세션 행 아래 Background 줄로 보인다.

### 고친 것

- 채팅 보기의 `/background`, `/bg`가 동작하지 않던 문제 (gateway가 거절했다).
- 백그라운드 작업이 부모와 상관없는 새 세션처럼 보이던 문제.

### 설치

| OS | 파일 |
|---|---|
